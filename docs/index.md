# Documentation only

This is project documentation. **GitHub Pages does not run the Aries Magic ASP.NET Core MVC application or SQL Server.** A successful Pages build is not a successful application deployment.

The actual **closed-alpha myASP.NET website** is:

**[Aries Magic on Windows IIS](https://ariesmagicartist-001-site1.htempurl.com/)**

Use that site for authorized alpha login, booking and payment workflows. This documentation contains no login, registration, booking or payment interface.
